ThinkDo 是面向个人知识管理与任务执行的智能助手平台。

## 核心定位

围绕「智能对话 + 知识库(RAG) + 笔记 + 计划管理」构建一体化能力闭环，帮助用户把分散的信息、待办事项、学习资料和日常记录统一沉淀到同一平台中。

## 主要功能模块

1. **智能对话与问答**：AI 对话界面，支持实时交流和辅助回答
2. **知识库管理**：文档上传、分类、检索，支持 RAG 检索增强
3. **笔记记录**：基于 TipTap 的富文本编辑器，支持 AI 润色/扩写/纠错
4. **计划管理**：计划创建、步骤拆解、每日清单、四象限视图
5. **管理员后台**：运营总览、用户管理、意图树配置、系统策略等

## 技术架构

- 前端：Vue 3.5 + TypeScript + Vite + shadcn-vue + Tailwind CSS
- 后端：Spring Boot 3.5 + JDK 21（端口 8091）
- 数据库：MySQL + Milvus（向量存储）
- AI 能力：支持多模型路由（百炼、硅基流动）

## Why: 项目背景

用户在知识管理与日常规划中面临"内容很多、查找很慢、计划很多、落地很难"的实际问题。ThinkDo 通过整合智能问答、知识库、笔记和计划管理能力，形成从记录、沉淀、检索到执行的完整闭环。

## How to apply:

在开发新功能或修改现有功能时，需考虑：
- 功能是否符合"知识沉淀 + 行动落地"的核心定位
- 是否需要与后端 RAG、AI 能力对接
- 用户界面是否简洁统一，使用 shadcn-vue 组件
- API 接口是否与后端 Controller 保持一致
